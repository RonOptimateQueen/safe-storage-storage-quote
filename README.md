# ארכיון — טופס חיצוני להצעת מחיר לאחסנה

> היישום הזה הוצא משימוש ב־2026-10-04. האפיון המאושר קובע שהעובד מכין את הצעת האחסנה בתוך Fireberry ושולח ללקוח את ההצעה המוגמרת; הלקוח אינו מקבל טופס תמחור לעריכה. אין לפרסם או לחבר מחדש את היישום ללא החלטה מפורשת שמשנה את האפיון.

אב־טיפוס היסטורי לטופס הצעת מחיר לאחסנה ללא חתימה. הוא נשמר לצורכי תיעוד בלבד וכלל:

- חישוב מחיר חודשי לפי נפח בקוב כפול מחיר לקוב.
- הצגת מחיר לקוב במסמך רק מ־8 קוב ומעלה.
- העלמת מחיר הובלה או סבלות כאשר השדה ריק או אפס.
- תצוגה מקדימה והדפסה של ההצעה לפי נוסח המקור.
- מילוי מקדים מאובטח מכרטיס לקוח ושמירה אידמפוטנטית דרך API.

ללא הגדרת Runtime הגרסה המקומית אינה כותבת ל־Fireberry, אינה שולחת ללקוח ואינה מפעילה EasyDo או Make. אין סביבת ייצור פעילה ואין workflow לפריסה.

שני תרחישי Make ההיסטוריים `7765306` ו־`7765308` מסומנים `OBSOLETE`, כבויים ואסור להפעילם. אתר GitHub Pages הוסר והמאגר הוגדר פרטי.

```powershell
npm install
npm test
npm run build
npm run dev
```
