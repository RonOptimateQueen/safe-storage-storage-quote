# מסמך הצעת מחיר לאחסנה לצפייה בלבד

היישום מציג ללקוח הצעת אחסנה שהוכנה מראש ב־Fireberry. אין בו שדות עריכה, שמירת מחירים או חתימה.

- הקישור מכיל token אטום בלבד ואינו חושף מזהי Fireberry או פרטי לקוח ב־URL.
- Make מאמתת hash, תוקף וביטול, ואז קוראת בזמן אמת את `Quote4`, הלקוח ו־`QuoteLine1000`.
- נפח ומחיר לקוב מגיעים משורת האחסנה. מחיר לקוב מוצג במסמך רק מ־8 קוב ומעלה.
- הובלה וסבלות מוצגות רק כאשר קיימת שורת הצעה מתומחרת.
- אפשר להדפיס או לשמור כ־PDF ולפתוח הודעת מייל או WhatsApp מוכנה עם קישור למסמך.
- אין EasyDo ואין חתימה.

תרחישי Make:

- `7765306` — יצירת קישור אטום והחזרתו לשדה הנעול `Quote4.pcfstoragequotedocumenturl`.
- `7765308` — API לקריאה בלבד. תומך `GET` ו־`OPTIONS`; כל `POST` נדחה ב־405.

```powershell
npm install
npm test
npm run build
npm run dev
```
