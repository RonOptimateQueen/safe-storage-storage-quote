# טופס הצעת מחיר לאחסנה

טופס פנימי להצעת מחיר לאחסנה ללא חתימה. היישום כולל:

- חישוב מחיר חודשי לפי נפח בקוב כפול מחיר לקוב.
- הצגת מחיר לקוב במסמך רק מ־8 קוב ומעלה.
- העלמת מחיר הובלה או סבלות כאשר השדה ריק או אפס.
- תצוגה מקדימה והדפסה של ההצעה לפי נוסח המקור.
- מילוי מקדים מאובטח מכרטיס לקוח ושמירה אידמפוטנטית דרך API.

ללא הגדרת Runtime הגרסה המקומית אינה כותבת ל־Fireberry, אינה שולחת ללקוח ואינה מפעילה EasyDo או Make. בסביבת הייצור ה־workflow יוצר `runtime-config.js` מתוך GitHub Actions secret, כך שכתובת החיבור אינה נשמרת בקוד המקור:

```html
<script>
  window.__STORAGE_QUOTE_CONFIG__ = {
    endpointUrl: "https://example.invalid/storage-quote",
    tokenQueryKey: "token"
  };
</script>
```

הקישור חייב להכיל טוקן אטום. כתובת החיבור שמגיעה לדפדפן אינה מנגנון הזדהות; ההגנה נשענת על טוקן אטום, תוקף, CORS ואידמפוטנטיות. אין לשמור בקוד מזהי Fireberry, כתובת Webhook חיה או סוד אחר.

```powershell
npm install
npm test
npm run build
npm run dev
```
